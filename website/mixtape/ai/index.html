Send your chosen YouTube recordings from ChatGPT to CD Studio, in the order you want to hear them.

Open ChatGPT Plugins ↗

  2. Name it Mixtape. Paste this server URL and select No authentication.
  3. Choose Create as a plugin, then connect it.
