Permissions & safety

Accessibility is required to pause system-wide input. CleanPause runs on your Mac; this page does not request that permission.

Touch ID and the power button are hardware-controlled and cannot be blocked. Cleaning Mode is not a security lock.

Version 0.1.9 is Developer ID signed and notarized by Apple. Notarization is a security check, not a guarantee of compatibility with every setup.

Windows preview & safety

This is an unsigned test build, not a verified Windows release. The Mac Accessibility permission does not apply. Open at Login and Ctrl + Alt + Win + P are optional in Settings.

Pointer movement remains available. Power / Fn keys, Windows security screens and some touch gestures cannot be guaranteed paused. Cleaning Mode is not a security lock.

No input is saved or uploaded. This preview is unsigned. Windows may show a security warning, and managed computers may block it. Real-device testing is still pending. Read the included READ-ME-FIRST.txt before testing.
