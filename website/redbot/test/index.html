找一篇收藏，
解决一个眼前的问题。

这是邀请码试用。先在电脑显示登录码，用手机上的小红书扫码确认；同一部手机登录尚未完成验证。测试电脑离线时无法同步。

  1. 打开 RedBot。先说说你认为它能帮你做什么，再点“连接小红书”。
  2. 输入收到的邀请码，阅读数据保管方式，获取登录码并在小红书确认。能否独立完成？
  3. 看同步状态。能否分清“本次看到多少条”和“所有收藏都已读完”？
  4. 说出一个现在想解决的问题，或在“我的收藏”里搜索。打开一篇并读取正文，结果是否与原帖相符？
  5. 查看免费、广告与收费条件线索。是否知道哪些已经核实、哪些还没有？可选：修改目标并复制一份执行指令。
  6. 保存一条笔记或下一步，刷新页面再找回来。记录任何丢失、重复或让你困惑的地方。

测试时尽量先自己完成，卡住再问 Ming。没有邀请码也可用原创示例体验，但请注明未测试账号连接。
