开始前，你可能想知道。

登录以后，会自动更新吗？

默认在打开时检查连接，并在页面可见时每 15 分钟发起一次扫描；可以关闭这个选项。关闭页面后不会发起新扫描，已开始的任务可以继续完成。它不是即时同步，也不会在你未打开页面时全天运行。

每次最多观察 2,000 条、滚动 100 次或等待 150 秒，始终标为部分覆盖。中断时可保留本次已读取的进度；下次从头扫描并去重，不代表已实现完整分页。

扫描会消耗 AI token 吗？

收藏扫描、去重和文字线索检查不调用大模型。可选的语义搜索会下载模型，在设备上运行，没有云端模型 token 账单，但会使用流量、内存和电量。

把内容交给 Codex 等 AI 助手进一步总结或开发，会消耗那个工具自身的额度；与收藏同步分开计算。

我的数据保存在哪里？怎么退出？

登录会话和读取到的收藏文本在 Ming 的测试服务分开保存，最长 7 天。点击“断开并删除服务端数据”即可删除该连接的服务端资料。当前浏览器保留离线副本，便于导出。

个人笔记、计划和整理状态保存在这个浏览器。换设备或清理浏览器之前，在“设置与我的数据”导出 JSON 备份；目前不会自动同步这些笔记到另一台设备。RedBot 不会发帖、点赞、评论或修改你的小红书收藏。

AI 搜索和总结分别能做什么？

语义搜索最多匹配前 300 个收藏和方法，帮助你在不记得原词时找到已保存文字。首次模型下载约 120 MB，另有运行库，来自 Hugging Face 和 jsDelivr；这些服务会收到普通网络请求信息。基础匹配无需下载。

网页展示的是已读取文字的摘录，不会生成新的 AI 总结，也没有自动读评论或转录视频。配套 Skill 可以让你自己的 AI 助手对已授权、真正读到的材料进一步总结和核实。

我想在 AI 助手里用它。

可从 GitHub 安装 RedBot Skill，提供选中的帖子、笔记或备份。安装 Skill 本身不会连接账号，也不会获得别人的收藏。网页版与 Skill 可以分别使用。
