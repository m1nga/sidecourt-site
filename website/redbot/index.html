开始前，你可能想知道。

登录以后，会自动更新吗？

默认在打开时检查连接，并在页面可见时每 15 分钟发起一次扫描；可以关闭这个选项。关闭页面后不会发起新扫描，已开始的任务可以继续完成。它不是即时同步，也不会在你未打开页面时全天运行。

没有固定收藏条数或滚动次数上限。每批收藏到达后立即显示，按来源实际分页结束判断完成。可以随时停止并保留已收到的收藏；再次检查会从头读取并去重。来源停滞、失败或读取超过 30 分钟时标为未完成，不会冒充全部同步。

会消耗 AI token 或产生费用吗？

收藏扫描、普通文字搜索和线索检查不调用大模型。语义搜索在你的设备上运行；概述和目标指令使用测试电脑上的本地模型，会处理 token，但当前没有云端模型 API 账单。视频转录也在测试电脑上完成。

这不等于没有成本：设备、内存、存储、电量、下载和维护仍有消耗。首次整理需要等待，重复查看会复用已保存结果。把指令交给 Codex 等助手执行，会消耗那个工具自身的额度。

需要再注册一个 RedBot 账号吗？

不需要，使用同一个 SideCourt 账号。小红书扫码用于授权读取你自己的收藏，是另一件事。旧用户可以确认关联现有收藏；关联后，同一账号可在其他设备恢复仍有效的连接与已读内容。个人笔记仍保存在各自浏览器，不会自动跨设备同步。

我的数据保存在哪里？怎么退出？

登录会话和读取到的收藏文本在 Ming 的测试服务分开保存，最长 7 天。点击“断开并删除服务端数据”即可删除该连接的服务端资料。当前浏览器保留离线副本，便于导出。

个人笔记、计划和整理状态保存在这个浏览器。换设备或清理浏览器之前，在“设置与我的数据”导出 JSON 备份；目前不会自动同步这些笔记到另一台设备。RedBot 不会发帖、点赞、评论或修改你的小红书收藏。

搜索、总结和视频分别能做什么？

普通搜索匹配已保存的正文、评论、视频文字和笔记，并显示命中片段。可选语义搜索覆盖当前可用收藏，没有前 300 条限制；首次需要下载固定版本模型，运行代码由本站提供。

打开已读收藏会按需生成简短概述和方法，结果随原文变化更新。视频目前分析语音和少量画面文字采样，不是完整视觉理解；转录和 AI 整理都可能有错。可以逐篇读取，也可以启动全部内容读取队列，已成功内容会复用。

我想在 AI 助手里用它。
