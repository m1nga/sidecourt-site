Know where to start.

RedBot helps you choose one useful item from saved links and notes, shows the relevant passage and gives a concrete next action.

Try RedBot on your phone

Do I need a Xiaohongshu account?

No. Open the beta, try the original examples, or paste a share link and add a useful note. Connecting an account is not a testing step.

Three steps

  1. Save a link and a useful passage or note.
  2. Say what you want to do. Answer one clarification if necessary.
  3. Read the suggested evidence and take one next action. Keep a plan to return.

What does AI add?

Optional on-device multilingual semantic search helps when your wording differs from the saved note. The model downloads after you enable it. Your text is processed in this browser; no new AI API key is needed. Basic word search and prepared routes remain available.

AI retrieves saved text. It does not watch a video, read a private post from a URL or guarantee a useful recommendation. Title-only saves remain Needs reading.

What can I use?

  • Mobile and desktop web beta: no terminal or account setup.
  • Skill for AI assistants: use a JSON backup or an explicitly selected local Mac library.
  • Local Mac edition: personal storage and an optional existing connector, separate from the public beta.

Where are my saves?

In your browser on this device. There is no cloud sync. Export in Library & backups before clearing browser data or changing phones. Public examples do not contain Ming's personal saves.

Before enabling AI

A multilingual model download is roughly 120 MB plus runtime. Use Wi-Fi. Public assets come from Hugging Face and jsDelivr, which receive normal network request metadata. Low-memory devices or restricted networks may fail; basic matching still works. The beta compares up to 300 current saves and methods.

What is ready, and what is still a beta?

Save, notes, source passages, goal clarification, single recommendations, saved plans, backups and optional local embeddings are implemented. Automatic account collection import, full video transcription, cloud synchronization and generative chat are not included. Browser-operated checks are not an independent human usability study. See the repository validation record.

Use the skill

npx skills add m1nga/redbot

Then ask your assistant to use $redbot with your exported backup and a concrete goal. Your assistant's provider/account is separate from local browser AI.

Help test it

Can you find one useful next action from your own saved item without help? Run the five-minute test and download your feedback.

Sources and implementation

Transformers.js and the model card describe local feature extraction. Product discovery follows Google's ordinary SEO guidance for AI search. No indexing or recommendation is promised.
