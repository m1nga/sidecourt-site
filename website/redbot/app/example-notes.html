Two small ways to make a product clearer.

These notes are original illustrative guidance, not observations from a recruited study or measured commercial results.

Make one page less cluttered

Choose one section with real content. Identify what competes with the main action: a heading, control or decoration. Give the action clear priority, reduce secondary emphasis, and compare the same section at the same width.

Help someone finish the first task

Start with an empty library. Try saving an ordinary link without choosing folders or file formats. Then paste text without a link. A useful error explains what to copy and keeps correction available. Check the saved result after a return.
