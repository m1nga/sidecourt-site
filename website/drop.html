THE ORIGIN

This is where SideCourt began.

CleanPause started with a small, ordinary frustration: cleaning a Mac should not set it off. Making that tool brought back the pleasure of creating something on your own terms. SideCourt grew from wanting a place where work made with that feeling could be seen, tried and taken seriously.

WHY IT EXISTS

A quiet answer to an irritating little moment.

Wiping a keyboard can trigger shortcuts, volume changes and gestures. CleanPause gives the task a pause of its own.

THE MOVE

Start. Clean. Come back.

  1. 01Start.

    Allow Accessibility once, then click Start Cleaning on the app’s home screen.

  2. 02Clean.

    Wipe the keyboard and trackpad while input is paused.

  3. 03Come back.

    Type done or hold the return ring for three seconds. Mac Cleaning Mode ends automatically after 30 minutes.

Power controls, security screens and some system gestures cannot be guaranteed paused. This is a cleaning tool, not a security lock.
