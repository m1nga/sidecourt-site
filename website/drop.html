FROM THE AUTHOR

Why it exists.

Wiping a keyboard can set off shortcuts, volume changes and gestures. CleanPause gives that small task a quiet moment of its own.

Use & compatibility ＋

Allow Accessibility once, then start Cleaning Mode. Wipe your keyboard and trackpad. Type done or hold the return ring for three seconds to come back.

macOS 13+ · Apple silicon & Intel. Windows is an unsigned preview; device testing is pending. Mac Cleaning Mode ends automatically after 30 minutes. Power controls, security screens and some system gestures cannot be guaranteed paused. This is a cleaning tool, not a security lock.
