One DayCup, two ways in

Web 2.12: open the official app. On iPhone, use Safari → Share → Add to Home Screen. On Android, use Chrome → Install app. Core brewing and the local journal work offline after the first load.

iPhone app: available to invited testers through TestFlight. TestFlight currently offers 2.8 (8) to the owner; the updated 2.12 package is still in preparation. Public App Store availability is still pending.

Both editions use the same cup-recording system. The iPhone app also reads selected labels on-device. Web photo recognition is not connected; photo backgrounds and manual entry work on both.

Your records, your choice

Sign in or register with Google or email using one account with SideCourt. Open your private cloud library to keep equipment, beans, preferences and cups across devices. Guest use stays local, and guest records upload only when you choose to bring them.

Join TheClub with the same account and a public name, then choose which cups to share. Shared cups can connect people through the same machine, grinder, bean origin or chosen city. Your own history remains useful even if you never share.

Recipes are starting points, not guarantees. DayCup does not measure machine pressure or infer extraction yield without the required measurements. Core use needs no API key or paid subscription.

同一个 DayCup，两种打开方式

网页版 2.12：打开正式应用
iPhone 用 Safari → 分享 → 添加到主屏幕，Android 用 Chrome → 安装应用，首次加载后核心冲煮和本机日志可离线使用

iPhone App：目前通过 TestFlight 邀请测试
本人 TestFlight 当前可安装版为 2.8（8），新版 2.12 安装包仍在准备，公开 App Store 上架尚未完成

网页和 iPhone 使用同一套单杯记录系统，iPhone 另有本机标签识别，网页版目前手动填写，两端都可用照片制作分享图

记录放在哪里，由你选择

使用 Google 或邮箱登录、注册，与 SideCourt 共用一个账号，打开私人云端库后，器材、豆子、偏好与冲煮记录可跨设备保留，也可以先以访客身份体验，本机记录只有在你选择带上它们时才会上传

TheClub 无需邀请码，使用同一账号设置公开昵称，就能选择分享一杯，也可通过同款咖啡机、磨豆机、豆子产地或主动选择的城市找到共同点，即使从不分享，自己的冲煮历史也有价值

配方是起点，不保证口味结果，DayCup 不读取机器压力，也不会在缺少必要测量时推算萃取率，核心使用无需 API 密钥或付费订阅
