你的咖啡记录，留在你这里。

Daycup 网页版只用本地的固定规则计算配方。没有账号、没有 AI 调用、没有统计 SDK、不需要 API Key，也不会自动上传你的冲煮记录。

设备、豆子、配方、笔记和反馈保存在这个浏览器的 IndexedDB 里。可下载的 HTML 文件只包含程序和资料库，不包含你之后输入的记录。换浏览器、换设备或清理浏览器数据之前，请先在「我的数据」导出 JSON 备份。

本地数据和导出的 JSON 都没有加密。使用同一个浏览器配置的人都能看到它们。SideCourt 的子路径不是独立的安全源，同一站点上受信任的脚本可以访问同源存储。

旧版本按账号保存的本地库会原样留在设备上。恢复需要你手动操作；程序不会登录旧服务，也不会自动合并旧记录。清空当前本地库不会删除任何云端记录。

打开厂商链接会离开 Daycup。托管在网站上的版本会向站点请求静态程序文件，站点可能按自己的政策保留访问日志。

没有备份的情况下清空本地数据是不可恢复的。申请持久化存储只是尽力保护。隐私浏览窗口不适合长期保存记录。

Your coffee stays here.

This browser edition uses local, deterministic rules. It has no account, AI calls, analytics SDK, required API key or automatic upload of your brew records.

IndexedDB stores equipment, beans, recipes, notes and feedback in this browser profile. The downloadable HTML contains the application and catalogues, not your later records. Export a JSON backup from My data before changing browser or device, or before clearing browser data.

Local data and exported JSON are not encrypted. Anyone using this browser profile may access them. A subpath on SideCourt is not a separate security origin; trusted scripts on that origin can access origin storage.

Older separate account libraries remain on the device. Recovery is explicit; the app neither signs in to the old service nor merges old records automatically. Clearing this browser library does not delete any cloud records.

Opening a manufacturer link is your choice and leaves Daycup. A hosted edition also makes ordinary requests to its host for static application files; that host may retain access logs under its own policy.

Clearing local data is permanent without a backup. A request for persistent browser storage is only a best-effort protection. A private browsing session is not a reliable permanent library.
